How to Run the Game Locally

First, create a new folder on your computer for the game
Create three files in this folder with these exact names:

index.html
game.js
styles.css


Copy the code from each of the provided files into your newly created files
Open index.html in a web browser (Chrome, Firefox, Safari, etc.)

That's it! The game should run immediately in your browser.
What the Game Includes
This is a complete Snakes and Ladders board game with:

A 10x10 game board numbered from 1 to 100
Multiple player support (2-4 players)
Animated dice
Visual representations of snakes and ladders on the board
Player position tracking
Win condition detection
A start menu to customize player names

Game Features

Player Customization: Start with 2-4 players and customize their names
Visual Dice: See the dice roll with animated dots
Turn-Based Gameplay: Players take turns rolling and moving
Snakes and Ladders: Players climb ladders to higher positions and slide down snakes to lower positions
Win Detection: First player to reach position 100 wins the game
Responsive Design: The game works on various screen sizes

The code is already complete and should work perfectly after you copy it to the three files and open the HTML file in your browser. No additional setup or installation is required since it uses only standard web technologies.
